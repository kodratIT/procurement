# F1.6 Filament free plugin compatibility

Baseline checked against Laravel 13.29.0, Filament 5.7.6, PHP 8.4.5, and Composer 2.10.3 on 2026-08-30.

## Installed and configured

| Package | Version | Decision |
| --- | --- | --- |
| `bezhansalleh/filament-shield` | 4.3.1 | Already installed; supports Filament 4/5, Laravel 11/12/13, and Spatie Permission 6/7/8. |
| `spatie/laravel-permission` | 8.3.0 | Already installed transitively and configured through `config/permission.php`; teams remain disabled because office scope is enforced by application assignments. |
| `spatie/laravel-activitylog` | 4.12.3 | Installed explicitly; supports Laravel 8 through 13. Config published to `config/activitylog.php`. Existing activity migration is retained. |

Shield and Permission remain authorization infrastructure only. They do not replace the active-office assignment gate in `User::canAccessPanel()` or domain policies. Activity Log is supplemental audit telemetry; approval history remains in the procurement domain tables.

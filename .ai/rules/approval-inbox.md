# Approval Inbox

## Gunakan filter kolom dan tab status baku
Tabel Purchase Request dan Approval menggunakan leek/filament-header-filters untuk menempatkan filter pada header kolom; panel filter terpisah disembunyikan. Tab PR memakai label baku Semua, Draft, Diajukan, Diproses, Dikembalikan, Ditolak, Disetujui, dan Dibatalkan. Status workflow dinamis dikelompokkan ke Diproses.
